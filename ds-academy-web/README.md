# DS Science Academy — Website

Client project for DS Science Academy, Gangapur City. Split into two independent parts.

## `app/` — the real product

Next.js app (public site + admin panel + its own Postgres/Prisma DB). Zero coupling to Mentora —
own DB, own auth, own deploy. See `app/README.md`, `app/SETUP.md` and `app/GO_LIVE.md` for setup
and deployment.

**Status as of 2026-08-13: `npm install` + `prisma migrate dev` + `db:seed` + `npm run dev` all ran
successfully against a real Supabase project for the first time — home page, admissions page and
the admin panel (login + the new admissionSteps/demoHighlights managers) verified working
end-to-end in a browser.** Original blockers from the old monorepo location, now resolved:

1. ~~`app/.env.example` missing~~ — reconstructed from `SETUP.md`/`GO_LIVE.md`, real `app/.env`
   created and working (not committed — see `.gitignore`).
2. ~~No `package-lock.json`~~ — generated by `npm install` (411 packages).
3. ~~No `prisma/migrations/`~~ — `20260813050120_init` generated and applied. Note: Supabase's
   direct host (`db.<ref>.supabase.co:5432`) is IPv6-only and timed out on this network — `DIRECT_URL`
   uses the **session pooler** (`<pooler-host>:5432`, no `pgbouncer=true`) instead, which is IPv4-safe.
4. `tsc --noEmit` — still not run.

**Known, deliberately deferred: `npm audit` reports 6 vulnerabilities (5 high, 1 critical) in
`next@14.2.18`.** The only fix is a major-version jump to `next@16.3.0` (Next.js stopped shipping
14.x security patches) — a breaking change (e.g. `params`/`searchParams` become Promises in the App
Router) that would need a full re-test of every page. Decided 2026-08-13 to defer this until closer
to actual deploy, since the app is local-dev-only right now with no internet exposure — do the
upgrade + full re-verification together as one deploy-prep step, not before. **Do not run
`npm audit fix --force` casually — it will jump straight to 16.3.0.**

## `design-prototype/` — approved visual design

Single-file HTML prototype (`ds_website.html` is the master — edit only this one) that the UI in
`app/` was designed against. `ds_website_artifact.html` and `ds_site_deploy/` are generated from it
— never hand-edit, regenerate instead:

```bash
cd design-prototype && python -c "
import re
src = open('ds_website.html', encoding='utf-8').read()
style = re.search(r'<style>.*?</style>', src, re.S).group(0)
body  = re.search(r'<body>(.*?)</body>', src, re.S).group(1)
open('ds_website_artifact.html','w',encoding='utf-8').write(
    '<title>DS Science Academy — Website Prototype</title>\n' + style + '\n' + body.strip() + '\n')
dep = src.replace('<meta name=\"viewport\"','<meta name=\"robots\" content=\"noindex, nofollow\"/>\n<meta name=\"viewport\"',1)
open('ds_site_deploy/index.html','w',encoding='utf-8').write(dep)
"
```

`ds_site_deploy/` is the folder to drag into Netlify Drop for a public preview link to send DS.
`ds_panel_elite.html` / `ds_panel_pro.html` are earlier standalone admin-panel mockups, kept for
reference.

`assets/` — DS's real logo (`logo_dssa.png`) and their 2026 NEET result poster, both embedded as
base64 inside `ds_website.html` already; kept here as source files too.
